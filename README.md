# easylab-sdk-kotlin

Typed EasyLab client SDK for Kotlin/JVM over Connect (easylab.v1 + agent.v1
via the easylab gateway). Generated by buf from
[easylab-platform/proto](https://github.com/easylab-platform/proto).

```kotlin
val client = EasyLabClient(baseUrl = "https://easylab.example.com", token = "...")
val repos = client.lab.listRepos(ListReposRequest())
```

## Consumed as a Git artifact

```kotlin
// build.gradle.kts
repositories {
    maven(url = "https://maven.pkg.github.com/easylab-platform/easylab-sdk-kotlin")
}
dependencies {
    implementation("com.easylab:easylab-sdk:0.1.0")
}
```

## Build

```bash
gradle compileKotlin
```
