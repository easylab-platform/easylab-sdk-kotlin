# easylab-sdk-kotlin

EasyLab typed client SDK for Kotlin/JVM over Connect — **buf-generated code
only** (easylab.v1 + agent.v1 + worker.v1). No hand-written transport, auth, or
wrapper: the caller builds its own `ProtocolClientInterface` and passes it to
the generated service clients.

```kotlin
val protocolClient = ProtocolClient(
    httpClient = OkHttpClient(),
    config = ProtocolClientConfig(host = "https://easylab.example.com", networkProtocol = NetworkProtocol.CONNECT),
)
val lab = LabServiceClient(protocolClient)
val repos = lab.listRepos(ListReposRequest(), emptyMap())
```

Generated by buf from
[easylab-platform/proto](https://github.com/easylab-platform/proto).

## Consumed as a Git artifact

```kotlin
// build.gradle.kts
repositories {
    maven(url = "https://maven.pkg.github.com/easylab-platform/easylab-sdk-kotlin")
}
dependencies {
    implementation("com.easylab:easylab-sdk:0.2.0")
}
```

## Build

```bash
gradle compileKotlin
```
